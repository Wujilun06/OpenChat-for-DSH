# 里程碑

每段做完能自己验，验不过不进下一段。

## P0 骨架（done）

仓库、npm workspaces、TS、SQLite 表结构 v1、单账号密码登录（含失败锁定）、
`/api/health`、PWA manifest + 图标、微信风空聊天页、开机自启脚本、文档。

**验收**
- `npm run build` 三个包都过
- `npm run test` 服务端测试全绿
- 打开 8787 能看到登录页，密码对了进空聊天页
- 手机 Safari「添加到主屏幕」打开是全屏无地址栏（要等 https 配好）

## P1 文字聊天（done）

消息落库、SSE 推送、左右气泡、头像昵称、引用回复、正在输入、时间戳三档、
整轮出字（多条之间留间隔）、向上翻历史、断线补齐、连发合并（2 秒窗口）。

**验收**
- 电脑和手机同时开，一边发另一边 1 秒内出现
- 刷新页面不丢消息；切后台再回来把断掉那段补齐
- Enter 发送，Shift+Enter 换行（手机 Enter 直接发）
- 长按/点击能引用一条再发，气泡上方显示被引用的那行
- 点昵称：默认不显示 → 时分秒 → 年月日时分秒 → 收起
- 同一条消息重发不会出现两条（`client_id` 去重）
- 2 秒内连发三条，对面收到的是一轮回答而不是三轮

> 还没接 DSH，回答是 `config.mock` 那个假鱼回声。接上以后把它关掉，
> 换成真会话，前端一行不用改。

## P2 表情（done）

上传（选文件）、服务端存盘、GIF 首帧缩略图 + 右下角 GIF 角标、表情面板、
发送、软删（面板里消失但历史消息照显）、共享池上限 100、单文件 5MB。

**验收**
- 传一张 png 和一张 gif，两台设备都能在面板看到同一批
- gif 在面板里是静态首帧 + 角标；发出去的气泡里会动
- 删掉一个，面板没了，之前发过的消息还在
- 第 101 张被拒，超过 5MB 被拒

> 缩略图用 `sharp` 生成；同一张图重复上传不会占两个位，软删过的再传会复活。

## P2.5 附件与交互调整（done）

图片 / 视频 / 文件消息、加号菜单、图片看原图、右键/长按引用。

**验收**
- 加号菜单弹出四项：图片/视频、表情、文件、语音/视频（通话是占位）
- 传一张照片 → 白色图片气泡；点开能看原图，Esc 或点空白关掉
- 传一个视频 → 缩略图是首帧 + 播放角标；点开放大、居中自动播放（Safari 靠 Range）
- 传一个文件 → 白色文件卡片，点开下载
- 右键（电脑）或长按（手机）任意消息 → 出现引用栏
- 左键/单点文字、表情、语音消息 → 没反应；点图片/视频 → 看大图 / 播放
- 图片、视频的缩略图明显比表情大（长边至少 180）

## P3 语音（转写，不存音频）（done）

录音 ≤60 秒 → 上传 → ffmpeg 转 wav → SenseVoice 转写 → 立刻删临时音频 →
落一条语音消息（时长 + 转写文字）。气泡显示秒数，下面一行转写。

**验收**
- 点麦克风开始录，录音条显示计时，能取消 / 发送；到 60 秒自动停
- 发出去先出现语音气泡，下面「语音转文字中」+ 转圈；整段转完才一次性显示文字
- 转写文字是白底小卡片，跟气泡分开
- iPhone Safari 录一段中文，十秒内出转写
- 发完之后 `data/tmp/` 里找不到这段音频
- 超过 60 秒被拒；没听清有明确提示，且不产生半条消息
- 没权限 / 没装转写时，麦克风按钮直接告诉原因

## P4 通话占位（done）

语音 / 视频通话的入口、接口、状态机占位。不做实时通话。

**验收**
- 加号里点「语音/视频」→ 弹出「语音通话」「视频通话」两个选项
- 点任意一个，明确提示还没做，不会假装在拨号
- 服务端落一条 `calls` 记录（`state = unsupported`），并通过 SSE 广播 `call.state`
- `GET /api/calls/status` 明确回 `supported: false`
- 文档里这个占位接口的字段和以后怎么接都写清楚了

`agent.followup` + `session/event`；启动双通道过渡期；确认后停 QQ。

**验收**

- 停掉 QQ 桥以后，网页照常收发
- 我主动说的话在网页里也能看到（样式区分）
