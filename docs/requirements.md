# 需求决定记录

从 2026-11-15 那几轮对话里定下来的东西。改需求先改这里，免得后面记混。

## 形态

- 独立网页应用，自带后端；**不发布成 DSH 插件**。
- 未来并入一个多功能面板，面板还没定 → UI 要能被 iframe / Web Component 包起来。
- 开发期不接 DSH，继续走 QQ；P5 才接。
- 一对一聊天，单账号。

## 访问

- 外网访问，电脑当服务器。
- 本机没有公网 IPv4 / IPv6（实测：只有 `fc01::/64` 私有地址，IPv4 是 `10.150.235.x`），
  所以走隧道。
- 路线：**Tailscale Funnel**（https、免装 App），私网模式留成配置开关。
- 手机：iPhone Safari，添加到主屏幕当 App 用。PWA 要求 https。
- 登录：一个账号 + 密码；密码写在 `config.json`。
- 电脑要开机自启；以后可能有定时开关机脚本。

## 聊天

- 微信风：左右气泡、头像昵称、引用回复、正在输入。
- 时间戳默认不显示；点昵称出现时分秒，再点加上年月日（年月日时分秒），再点收起。
- 回答整轮结束一起出，多条之间留间隔。
- Markdown、工具调用、思考过程**不进聊天区**，留在 DSH 那边。
- 引用回复、正在输入要做；已读、撤回、编辑不做。
- **引用触发**：电脑右键、手机长按；左键/单点不引用。
- **点图片看原图**：图片消息左键（手机单点）打开大图；文字、表情、语音左键无反应。
- **发送语义（C5）**：点发送立刻落库并开一轮；2 秒内连发的几条并成一轮；
  对方正在回的时候再发，排到下一轮。
- **我说的话（C6）**：只要是我说的话都进网页（正文），包括我主动开口的那几轮；
  思考过程、工具调用留在 DSH 会话里，不进聊天区。

## 附件

- 加号菜单四项：图片/视频、表情、文件、语音/视频通话（通话先占位）；
  顶栏不再放通话按钮。
- 图片/视频/文件走系统文件选择器；上传后单独成一条消息。
- 默认上限（`config.attachment` 可改）：图片 10 MB、视频 50 MB、文件 50 MB。
- 表情和普通图片是两套：表情进共享池、发出来是小图；普通图片是白框图片气泡，点开看原图。
- 缩略图大小：表情长边 132；图片/视频长边夹在 180–240，保证一眼看出不是表情。
- 视频缩略图是首帧，中间叠「外圆环 + 实心三角」的播放标记。
- 点开：按画幅放大（94% 宽 / 88% 高以内尽量铺满），视频居中自动播放。

## 表情

- 共享池，上限 100，单文件 5MB，jpg/png/webp/gif。
- 服务器端生成缩略图；gif 取首帧，右下角标 GIF。
- 只在表情面板里删除（软删），历史消息照显。
- 两个人共用一个池子，鱼也能发。

## 语音

- 语音消息要做，但**不存音频**：录音 → 上传 → 转写 → 只留时长和文字。
- 气泡显示秒数，下面一行是转写。
- 最长 60 秒。
- 以后可能把音频加回来 → 表里留了 `audio_ref`，API 留了扩展位。
- 语音电话 / 视频电话：只留按钮、接口、状态机，不做实时通话。
